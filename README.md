#Japanituremod - Hub & Issue / Block Request

ようこそ！ここは Minecraft 用・現代日本家具＆家電 MOD **「Japanituremod」** の公式ホームページ兼、不具合報告（Issue）・追加ブロック＆アイテム申請窓口です。

## バグ・不具合報告

ゲーム中に発生した表示バグ（手持ち時の向き・サイズずれなど）、クラッシュ、当たり判定の異常などは **Issues** から報告をお願いします。

1. 上部の **[Issues](../../issues)** タブを開く
2. **「New Issue」** を押す
3. 以下の情報を記載して送信してください：
   - **Minecraftのバージョン**（例: 1.19.2 / 1.20.1 等）
   - **MODローダー**（Fabric / Forge 等）
   - **Japanituremod のバージョン**
   - **発生した問題の詳細・再現手順**（クラッシュログやスクリーンショットがあると大変助かります）

## 追加ブロック・家具・家電の申請

「現代の部屋作りに使うこの家電が欲しい！」「都市開発や駅作りに使える建材を増やしてほしい！」などのアイデアを大募集しています。

1. **[Issues](../../issues)** タブを開き、新規 Issue（または専用テンプレート）を作成
2. 以下の内容を記入してください：
   - **アイテム/ブロックの名前**（例: 特定の家電、家具、道路・駅用建材 など）
   - **用途や見た目のイメージ**（実物の写真や参考画像があるとスムーズです）
   - **希望するギミック**（右クリックでの動作、光る仕様、アニメーション等）

## 動作環境・前提MOD

バージョンに応じて以下の前提MODが必要となる場合があります。導入前にご確認ください。

- **GeckoLib** (Japaniture 3.0.0 以降などアニメーションブロック用)
- **ModernJapanCityMod** (室外機など一部連携アイテム利用時)

## 利用規約・ガイドライン

- **動画配信・生放送:** 事前連絡なしで自由にご利用いただけます。（配信や動画の概要欄等にMOD名を記載していただけると嬉しいです！）
- **MODパックへの導入:** クレジットを明記していただければご自由にどうぞ。
